Deep Merge QA Evidence
======================

Output: {"a":{"b":99,"c":2}}

Verification:
- Base object: {a: {b: 1, c: 2}}
- Override object: {a: {b: 99}}
- Result correctly merges nested objects
- Override value (b: 99) takes precedence
- Base value (c: 2) is preserved when not overridden
- Nested object merge works as specified
